# RPAY — Virtual UPI Sandbox

RPAY is a completely virtual, risk-free fintech sandbox that functions like a modern Unified Payments Interface (UPI) application. Instead of real money, it uses a closed-loop digital economy where users can practice peer-to-peer transfers and simulated checkouts in a polished, secure environment.

> **Important:** RPAY is a simulation. It does not process real money, connect to bank accounts, or support fiat currency transactions.

## The Kinex (K) Economy

The entire RPAY network runs on **Kinex (K)**, a native digital asset designed for the sandbox environment.

- **No real money required:** Users do not need bank accounts, credit cards, or fiat currencies.
- **Starting capital:** New users automatically receive a **K 10,000 sign-up bonus** upon registration.
- **Visual identity:** Kinex is represented by a custom glowing cyan, neon-metallic coin integrated into the main balance dashboard.

## Core Payment Features

### Global Directory

Users register with a unique handle, such as `name@rpay`, and can instantly search the network directory to send Kinex without maintaining a traditional friends list.

### Dynamic QR Scanner

The built-in camera tool can read:

- Standard merchant UPI codes, including `upi://pay...` links
- Plain-text payment IDs

After scanning, RPAY launches a checkout screen with the amount and receiver pre-filled where available.

### Personal Receiving QR Codes

Every account includes a personal, scannable QR code that makes it easy for other users to send incoming Kinex payments.

### Passbook Ledger

A complete, real-time transaction history tracks the flow of funds. Incoming transfers are displayed in green, while outgoing payments are displayed in red.

## Security and Interface

### Custom PIN Numpads

To prevent mobile keyboards from shifting the screen layout, all four-digit PIN entries—including login and checkout authorization—use a dedicated built-in HTML number pad.

### Privacy Toggles

Users can tap the visibility eye icon on the dashboard to instantly hide or reveal their total Kinex balance from people nearby.

### Two-Step Workflows

Authentication and payment flows use a clean two-step process:

1. Enter the amount or recipient ID.
2. Continue to the secure PIN screen to authorize the action.

## Administration and Gamification

### Operator Controls

The central admin account, **Boss0**, can monitor and manage the network by:

- Sending global broadcast warnings
- Manually adjusting Kinex balances
- Freezing suspicious accounts
- Terminating users entirely

These controls are intended for sandbox administration, testing, demonstrations, and controlled gameplay scenarios.

## Disclaimer

RPAY is a closed-loop fintech simulation for educational, testing, and entertainment purposes. Kinex has no monetary value and cannot be exchanged for real currency. Never enter real banking credentials, card details, or other sensitive financial information into the application.
